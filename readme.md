
# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts for the
AttendX student attendance application.

## Test Scripts
1. test_login.py
   - Checks login input validation.
   - Checks the empty-credentials scenario.

2. test_attendance.py
   - Checks attendance input validation.
   - Checks the missing-student scenario.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- Python

## Purpose
To maintain test scripts under version control and
demonstrate commits, remote synchronization, and history.

## Execution
Run the scripts using:

python test_login.py
python test_attendance.py

Note: These are demonstration scripts and require
application integration for end-to-end testing.

## Version Control Demonstration
This project demonstrates local commits, remote pushes,
web-based editing, and pulling changes from GitHub.
